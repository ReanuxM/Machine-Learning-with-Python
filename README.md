# Machine Learning with Python

A collection of hands-on machine learning projects built with Python and Scikit-learn, covering regression and classification workflows from data exploration to model evaluation.

## 📂 Projects

| # | Project | Task | Model | Highlight |
|---|---------|------|-------|-----------|
| 1 | [CO2 Emission Prediction](./Machine%20Learning%20with%20Python/Lab1) | Regression | Simple Linear Regression | R² = 0.76 |
| 2 | [CO2 Emission Prediction (Multi-feature)](./Machine%20Learning%20with%20Python/Lab2) | Regression | Multiple Linear Regression | 3D regression visualization |
| 3 | [Logistic Regression Classifier](./Machine%20Learning%20with%20Python/Lab3_Logistic_Regression) | Classification | Logistic Regression | Confusion matrix + log-loss evaluation |
| 5 | [Drug Classification](./Machine%20Learning%20with%20Python/Lab5_Decision_Tree) | Multi-class Classification | Decision Tree | 5-class prescription model, ~98% test accuracy |
| 6 | [NYC Taxi Tip Prediction](./Machine%20Learning%20with%20Python/Lab6_Regression_Trees) | Regression | Decision Tree Regressor | Correlation-driven feature selection, depth vs. bias–variance |
| 7 | [Credit Card Fraud Detection](./Machine%20Learning%20with%20Python/Lab7_SVM) | Classification (imbalanced) | SVM vs. Decision Tree | ROC-AUC benchmark, sample-weighted training |

Each project folder contains a fully documented Jupyter notebook. Labs follow the IBM *Machine Learning with Python* curriculum.

## 🛠️ Tech Stack

- **Language:** Python 3
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
- **Environment:** Jupyter Notebook

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/ReanuxM/Machine-Learning-with-Python.git
cd Machine-Learning-with-Python

# Install dependencies
pip install numpy pandas matplotlib seaborn scikit-learn jupyter

# Launch Jupyter
jupyter notebook
```

## 🎯 What These Projects Demonstrate

- Complete ML workflow: loading → cleaning → EDA → feature selection → training → evaluation
- A range of algorithms: linear & logistic regression, decision trees, regression trees, and SVM
- Regression metrics (MAE, MSE, RMSE, R²) and classification metrics (accuracy, log-loss, confusion matrix, **ROC-AUC**)
- Handling **imbalanced data** with sample weighting, and reading the bias–variance tradeoff via tree depth
- Feature comparison and selection based on measured performance
- Data visualization in 2D and 3D
